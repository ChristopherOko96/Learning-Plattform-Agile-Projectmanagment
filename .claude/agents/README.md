# Agenten für Claude in diesem Projekt

In diesem Ordner sind zwei spezialisierte Agenten für die Arbeit mit dem Projekt bereitgestellt:

- `web-app-development.agent.md`: Agent für Web-App-Entwicklung, Design und Implementierung.
- `code-review-debug.agent.md`: Agent für Code-Review, Debugging und Qualitätsverbesserung.

Verwendung:
- Öffne die gewünschten Agentenkonfigurationsdateien in VS Code.
- Nutze sie als Referenz, wenn du Claude / Agenten in diesem Workspace starten möchtest.
- Passe die Beschreibungen an, falls du die Rolle oder den Schwerpunkt verändern willst.

Parallelarbeit:
- Frontend- und Backend-Agenten können gleichzeitig arbeiten.
- Definiere vorab API-Verträge und Datenmodelle.
- Der Web-App-Agent erstellt das UI und den Spielablauf.
- Der Code-Review-Agent prüft Schnittstellen, Sicherheit und Stabilität.
